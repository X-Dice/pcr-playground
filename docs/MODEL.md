# PCR Playground 教学模型

模型版本：`1.0.0-teaching`。这是帮助新手比较变量的确定性教学模拟，尚未用真实实验数据拟合或校准。它不预测实际浓度、真实成功率、精确最优温度或序列正确性。结果不是实际 qPCR 测量。

## 有来源的原理与本项目的教学设定

官方资料支持以下定性关系：退火条件与引物、酶和缓冲体系有关；较低退火温度可能允许非特异结合，较高温度可能减少有效结合；热启动可减少准备阶段的非特异反应；扩增后期进入平台期；高保真涉及复制准确性，并不等于所有条件下产量最高。参考链接见 [REFERENCES.md](REFERENCES.md)。

本项目所有数值曲线系数、样本结合位点、杂带长度、酶配置系数、100 的容量、随机扰动幅度及模板相对量换算，均为作者自行选取的教学参数，不是厂商测试值。名称中的 Q5 只用于认识酶种类及协议差异；该配置不是经验证的 Q5 性能模型。

## 单位与比较

- `template` 表示模板加入量的相对输入，范围 0–10000，不是拷贝数或 ng。
- `target`、`offTarget`、`dimer` 是统一尺度下新增 DNA 产物的相对质量量，任何实验的总量都不超过 100。不得换算为 ng/µL。
- 每次模拟使用同一个容量尺度，不按当前最高结果重新归一化，所以跨温度和历史记录仍可比较。
- `purity` 是目标相对量除以全部产物相对量，范围 0–1；没有产物时返回 0。它不代表样品纯度的实测值，更不代表序列正确率。
- 为避免把极微量产物的高数学占比当成理想结果，界面在总相对量低于 0.1 时隐藏占比并标记“产物过少”。0.1 仅是教学显示阈值，不是仪器的真实检测限；CSV 保留模型原始数值。
- 初始模板与新增扩增产物分开处理：循环 0 的新增产物量全部为 0。教学模型没有逐条追踪最初几轮长短链的真实形成过程。

## 结合与产物增长

对目标片段、每一条预设非特异片段和引物二聚体分别计算有效结合因子：

`binding(T_eff, T_a) = 1 / (1 + exp((T_a - T_eff) / 1.8))`

`T_eff` 由引物参考 Tm、酶配置偏移及弱结合位点偏移构成。这里的 1.8 和偏移都是教学参数；输入的 Tm 也只是参考值，没有根据真实序列、盐、Mg²⁺或浓度计算。

每类产物本轮提出的增量是：

`(已有该类产物 + 该类启动来源项) × 有效扩增效率 × 本轮扰动 × 剩余容量比例`

其中，剩余容量比例为 `max(0, 1 - 全部产物 / 100)`。所有类别共享容量；若合计提出的增量超出剩余容量，按比例缩小分配。因此产量非负、总量有限，并逐渐进入平台。它没有逐项模拟 dNTP、Mg²⁺、引物和活性酶的动力学。

较长目标片段有一个教学用效率惩罚。变更长度也会改变同等模板相对输入下的质量来源项，不能把它解释为实验上“片段越长必定越少”。变性、延伸及热启动激活均假设已按各酶适用条件完成，用户改变的退火温度不会替代整套真实 PCR 协议。

## 样本与酶配置

| 样本 | 预设内容 |
| --- | --- |
| 干净模板 | 不存在非特异位点；二聚体形成倾向较低。 |
| 复杂模板 | 两个预设弱结合位点，对应 300 bp 与 1000 bp 片段；有效结合参考值比目标低 7℃、10℃。这些不是已验证引物的预测结果。 |
| 低模板挑战 | 不存在非特异位点，允许二聚体形成；界面选中该预设时将模板加入量设为 3，模型仍以传入的 `template` 为准。 |

二聚体示意长度为 70 bp，不依赖目标模板，因此零模板对照也可能形成二聚体。没有目标模板时，目标及非特异模板产物均严格为 0。干净模板不会仅因温度低而凭空出现非特异片段。

普通 Taq、热启动型及 Q5 配置的效率上限分别设置为 0.84、0.82、0.79，结合偏移为 1.5℃、1.5℃、3.5℃。热启动型的非特异启动来源项乘 0.16，二聚体来源项乘 0.12，以示意减少早期非特异启动。其他系数在 `model.js` 中公开。**这些数值仅是教学设定，不可作为真实酶的比较数据或退火温度建议。**

模型没有序列、错配、真实引物二聚体自由能、酶校对错误率或污染过程。高保真配置不会被预设成所有条件下的产量冠军，也不会通过胶图暗示复制准确性。

## 随机种子与公平比较

种子由 0–4294967295 的整数给出。模型用同一确定性伪随机发生器，预先生成每轮目标、非特异及二聚体各自的 0.94–1.06 倍扰动。一次梯度的 6 管共享这张扰动表；单管模式在相同温度、种子和其他设置下必须得到完全相同的结果。

改变循环数保留前面轮次的同一扰动序列。相同设置与种子可重建完整曲线、终点和胶图数据；更换种子代表模型重复，不是来自真实实验的误差分布或置信区间。

## 胶图与曲线

胶图数据与终点指标取自同一组产物量。目标片段长度不会因退火温度或循环数变化；非特异片段与二聚体长度由样本预设固定。实际显示还有曝光和检测阈值，所以极少量产物可能在胶图上不可见。

扩增曲线显示“每轮模拟新增产物累计量”，不具备经过校准的荧光响应，不能用于产生实测 Cq/Ct。模拟胶图也不能确认序列正确。

## 导入边界与验证

`normalizeSettings()` 只接收普通对象。缺失字段采用默认值；未知字段、无效枚举、数值字符串、非有限值、超范围值，以及应为整数却带小数的值都会抛出错误，拒绝静默截断或转换。梯度最低温度必须严格低于最高温度。支持范围与界面一致。

`tests/model.test.mjs` 检查零循环、零模板、无预设杂带、温度过高抑制、弱位点低温扩增、平台期、酶配置边界、固定片段长度、跨模式相同随机扰动，以及多组极端参数下的容量和数据一致性。这些测试验证模型满足公开设定，不构成真实 PCR 预测准确性验证。
