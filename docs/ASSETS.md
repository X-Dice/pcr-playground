# Asset credits / 素材说明

The project uses original vector illustrations and interface graphics authored for PCR Playground. The laboratory scene, chart graphics, and theme decorations are produced by project code rather than copied artwork.

本项目的实验室插画、图表和主题装饰均为项目原创矢量与代码绘制素材，未复制其他网站的图片、模型或动画资源。

| Source | Use |
| --- | --- |
| `scene.js` | Original illustrated laboratory scene / 原创实验室场景 |
| `charts.js` | Code-generated charts / 程序绘制图表 |
| `style.css` | Original layouts, colors, and theme decorations / 原创布局、配色和主题装饰 |

Interaction inspiration: [Bruno Simon](https://bruno-simon.com/) and [Neal.fun](https://neal.fun/). These references inform the playful, exploratory approach. Their code, visual assets, and branding are not included. No affiliation or endorsement is implied.

交互灵感来自 Bruno Simon 与 Neal.fun 的探索式体验；没有使用其代码、素材或品牌元素，也不存在隶属或背书关系。
